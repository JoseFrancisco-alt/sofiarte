# Sofia — site

Site/portfólio da tatuadora Sofia ([@sofiarte_tattoo](https://www.instagram.com/sofiarte_tattoo/)), Maceió/AL.

HTML, CSS e JS puros, sem build. O site fica em `sofiarte/`. Os trabalhos, a seção "Ressignificar", as cicatrizadas, as viagens, os flashes e o número do WhatsApp são editados no topo de `sofiarte/script.js`.

- As fotos ficam em `sofiarte/img/` e foram tiradas do Instagram dela (out/2026). Troque pelos originais em alta quando ela mandar.
  - `w-*.jpg`: trabalhos da parede.
  - `r-*.jpg`: tatuagem sobre cicatriz.
  - `v-*.jpg`: viagens e natureza.
  - `sofia-pb.jpg`: foto do hero.
- Um trabalho sem foto mostra um desenho fine line no lugar.

Rodar local: `python -m http.server 5392 -d sofiarte`
